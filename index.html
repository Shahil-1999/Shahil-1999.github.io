What it does

Employee lifecycle

Onboarding, grades, confirmation letters, separation & exit interviews, all with approval workflows.

Attendance & leave

Biometric import, regularisation requests with manager approval, configurable leave categories and balances.

Payroll & compliance

CTC calculation, grade-based salary components, payslip generation, PF/ESI/PTax and bank-transfer reports.

Projects & tasks

Kanban/Scrum workflows, sprints, custom fields, worklogs, and git-provider integrations per project.

Reimbursements

Claim submission, approval routing, and spend analytics by category.

Multi-tenant billing

Plans, add-on modules, UPI-based subscription payments, and generated invoices per organisation.

Architecture

React SPA (Vite) → REST/JSON → Express 5 API → PostgreSQL (Sequelize) + Cloudflare R2 (files)

Frontend and backend deploy independently on Render; production data lives on Supabase Postgres. Every request is scoped to the caller's organisation, with role-based permissions enforced per module.
